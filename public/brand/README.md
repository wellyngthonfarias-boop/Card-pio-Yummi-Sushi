# Logo oficial

`yummi-sushi-logo.png` é o arquivo original fornecido, preservado sem alterações.
`yummi-sushi-logo.webp` é uma codificação lossless do mesmo arquivo, com dimensões e pixels RGBA idênticos, usada para exibição na página. Sem recortes, distorção, redimensionamento ou alteração de cores/tipografia.

Na revisão: PNG 1.365.046 bytes; WebP 810.650 bytes (redução de aproximadamente 40,6%). A equivalência foi verificada decodificando ambos e comparando todos os pixels.
