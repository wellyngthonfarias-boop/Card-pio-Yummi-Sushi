# Imagens provisórias

Os arquivos `placeholder-*.svg` são ilustrações vetoriais originais criadas neste projeto, sem assets externos. Não são fotografias do restaurante. Gerador: `scripts/create-placeholders.mjs`. Substituir pelas fotografias oficiais ao receber o cardápio definitivo.

`placeholder-bebida.svg` e `placeholder-sem-foto.svg` são símbolos neutros feitos localmente para preencher o campo de imagem dos itens ainda sem fotografia. Não são gerados pelo script. Os cards continuam usando os ícones aprovados; esses arquivos aparecem na visualização detalhada com a indicação "Foto em breve".
